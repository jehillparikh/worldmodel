9 Mathematical Foundations of World Models: A Contextual Guide

9.1 1. Probability Theory Fundamentals

9.1.1 1.1 Axioms of Probability

The axioms of probability form the bedrock of uncertainty quantification in world models. Let’s understand why each axiom matters:

  1. Non-negativity: P(A) ≥ 0
    • Why it matters: Ensures probabilities are meaningful and can be compared
    • Real-world example: When predicting the probability of a robot successfully grasping an object, negative probabilities would make no physical sense
    • Application: Used in ensuring valid probability distributions in neural network outputs through activation functions like softmax
  2. Normalization: P(Ω) = 1
    • Meaning: The total probability of all possible outcomes must sum to 1
    • Example: In a world model predicting weather, the probabilities of all possible weather conditions must sum to 100%
    • Implementation: Often enforced through normalization layers in neural networks
  3. Additivity: P(∪ᵢAᵢ) = ∑ᵢP(Aᵢ) for mutually exclusive events
    • Usage: Enables breaking complex events into simpler components
    • Example: Probability of a robot completing a task can be broken down into probabilities of individual sub-tasks
    • Key in practice: Used in hierarchical task planning and decision trees

9.1.2 1.2 Conditional Probability and Independence

The conditional probability formula: P(A|B) = P(A ∩ B) / P(B)

Context and Application: - What it means: The probability of A occurring, given that B has occurred - Practical use: In world models, used to update beliefs based on new observations - Example: - A = “Robot successfully completes task” - B = “Initial position is correct” - P(A|B) tells us success probability given correct starting position

Chain Rule expansion: P(A₁ ∩ A₂ ∩ … ∩ Aₙ) = P(A₁)P(A₂|A₁)P(A₃|A₁,A₂)…P(Aₙ|A₁,…,Aₙ₋₁)

Applications: - Sequential decision making in robotics - Language model probability calculations - Multi-step planning problems

9.1.3 1.3 Probability Distributions

9.1.3.1 Normal Distribution

f(x|μ,σ) = (1/√(2πσ²))exp(-(x-μ)²/(2σ²))

Why it’s important: - Central Limit Theorem makes it fundamental for many natural phenomena - Key properties that make it useful: 1. Symmetric about the mean 2. Defined by just two parameters (μ, σ) 3. Easy to work with mathematically

Applications in World Models: - Modeling sensor noise - Representing uncertainty in predictions - Generating exploration noise in reinforcement learning

9.2 2. Kullback-Leibler Divergence

9.2.1 2.1 Understanding KL Divergence

The discrete formula: D_{KL}(P||Q) = ∑ᵢ P(xᵢ)log(P(xᵢ)/Q(xᵢ))

Breaking it down: 1. P is the true distribution 2. Q is the approximating distribution 3. The sum measures total information loss

Practical Implications: - Used in training variational autoencoders - Measures how well a model’s predictions match reality - Guides model optimization

Example in World Models: - P: True physics of the environment - Q: Model’s prediction of physics - D_{KL} measures how well the model has learned the dynamics

9.2.2 2.2 Properties and Their Importance

  1. Non-negativity: D_{KL}(P||Q) ≥ 0
    • Ensures meaningful comparison
    • Zero only when distributions match perfectly
    • Used as a loss function component
  2. Asymmetry: D_{KL}(P||Q) ≠ D_{KL}(Q||P)
    • Practical impact: Choice of direction matters
    • Forward KL (P||Q): Mode-seeking behavior
    • Reverse KL (Q||P): Mode-covering behavior

9.3 3. Optimization Techniques

9.3.1 3.1 Gradient Descent and Variants

Basic gradient descent: θ_{t+1} = θ_t - η∇L(θ_t)

Understanding the components: - θ_t: Current parameters - η: Learning rate - ∇L: Gradient of loss function

Why it works: - Follows steepest descent direction - Guaranteed convergence for convex functions - Simple but effective

9.3.2 3.2 Adam Optimizer

The update rules: m_t = β₁m_{t-1} + (1-β₁)∇L(θ_t) v_t = β₂v_{t-1} + (1-β₂)(∇L(θ_t))² θ_{t+1} = θ_t - η * m̂_t/(√v̂_t + ε)

Key advantages: 1. Adaptive learning rates per parameter 2. Momentum for faster convergence 3. Bias correction for better early steps

When to use: - Non-stationary objectives - Noisy gradients - Large-scale problems

9.4 4. Practical World Model Implementation

9.4.1 4.1 Model Architecture Considerations

For a world model p(s_{t+1}|s_t,a_t):

  1. Deterministic component: μ_θ(s_t,a_t) = neural_network(s_t,a_t)
    • Predicts expected next state
    • Usually implemented as MLP or CNN
  2. Stochastic component: σ_θ(s_t,a_t) = positive_network(s_t,a_t)
    • Models uncertainty
    • Must ensure positive outputs

9.4.2 4.2 Training Objectives

Maximum Likelihood: L_ML = -E_{τ~D}[log p_θ(τ)]

Breaking it down: - τ: Trajectory of states and actions - D: Dataset of experiences - p_θ: Model’s probability distribution

Implementation tips: 1. Use mini-batches for stability 2. Apply gradient clipping 3. Monitor validation performance

9.4.3 4.3 Numerical Stability

Log-sum-exp trick: log(∑ᵢexp(xᵢ)) = a + log(∑ᵢexp(xᵢ-a)) where a = max(xᵢ)

Why it’s needed: - Prevents numerical overflow - Maintains numerical precision - Crucial for stable training

Implementation:

def log_sum_exp(x):
    a = x.max()
    return a + torch.log(torch.sum(torch.exp(x - a)))

9.5 5. Model Evaluation and Validation

9.5.1 5.1 Metrics

  1. Prediction Error: MSE = E[(s_{t+1} - ŝ_{t+1})²]
    • Measures accuracy of predictions
    • Lower is better
    • Scale depends on state space
  2. Log-Likelihood: LL = E[log p(s_{t+1}|s_t,a_t)]
    • Measures probability model assigns to true outcomes
    • Accounts for uncertainty
    • Better for comparing models

9.5.2 5.2 Validation Strategies

  1. K-fold cross-validation:
    • Split data into K folds
    • Train on K-1, test on 1
    • Rotate and average results
  2. Time-based splitting:
    • Train on earlier data
    • Test on later data
    • More realistic for sequential problems
